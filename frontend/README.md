# AdCraft AI 工作台前端

React与TypeScript的对话工作台，新入口为src/App.tsx，主要页面为src/pages/Workbench/index.tsx，API与类型分别在src/api/ai.ts和src/types/ai.ts。

开发：npm ci；npm run dev。默认5173，/api代理到8000。构建：npm run build。新版lint：npm run lint。所有源码由TypeScript strict检查；旧参考页面没有进入新版路由。

完整启动、AI模型配置、预构建网页与学习顺序请看项目根目录README.md和START_HERE.md。
